# Historical research receipts

These visualizations and summary receipts describe an earlier planner configuration. They are retained for provenance and are not the current live-product evidence. Complete raw population outputs/configurations and model checkpoints are not included here.

Dollar and time figures are proportional illustrations from simulated effort gaps, not measured real-world savings. Use `reports/sale_review/live_product/` for reproducible current results, and consult [`docs/EVIDENCE.md`](../../docs/EVIDENCE.md) for the limitations of each historical claim.
